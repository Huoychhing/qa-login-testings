# Login Page Test Cases

## TC001 - Valid Login
Test Objective: Verify that users can log in with valid credentials.

Test Steps:
1. Open the login page.
2. Enter a valid email.
3. Enter a valid password.
4. Click Login.

Expected Result:
User should successfully log in.

## TC002 - Invalid Password
Test Objective: Verify that users cannot log in with an incorrect password.

Test Steps:
1. Open the login page.
2. Enter a valid email.
3. Enter an incorrect password.
4. Click Login.

Expected Result:
The system should display an error message.
